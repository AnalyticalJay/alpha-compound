# Anabolics Africa Customer Experience Feature Slides

The slide set uses authentic Anabolics Africa UI screenshots in paired desktop-browser and mobile-phone mockups. It is designed as a 16:9 presentation/social feature carousel with a dark premium treatment, electric blue and red brand accents, and concise customer-facing feature copy.

| Slide | Customer benefit | Desktop UI reference | Mobile UI reference |
|---|---|---|---|
| 01 | Members-only catalogue access | Public homepage | Mobile checkout/navigation context |
| 02 | Build and submit a quote | Public catalogue | Mobile quote request and delivery details |
| 03 | Track quote progress | Customer quote detail | Mobile quote progress panel |
| 04 | Pay securely after approval | Customer quote detail | Mobile payment selection panel |
| 05 | Keep delivery visible | Customer quote detail | Mobile delivery-tracking panel |

Each slide pairs one real desktop screen with one real mobile screen. Headline copy is kept outside the application captures so the product interface remains authentic and legible.

## Visual Check

The opening access slide and the secure-payment slide were checked after rendering. Both retain the dark Anabolics Africa palette, readable high-contrast feature copy, a clearly framed desktop application reference, and a distinct mobile device mockup. The payment slide visibly preserves the real PayFast and Instant EFT choices from the customer order experience.
